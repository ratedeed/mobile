# RateDeed Mobile — Audit Report

**Date:** 2026-08-13
**Scope:** Mobile app `ratedeedmobile` (Expo / React Native, ~37k lines) — 111 source files.
**Method:** Two audits. (1) **Code audit**: 10 partitioned finder agents (security/money/races/correctness). (2) **Feature-flow & state-coverage audit**: 10 journey-tracing agents (dead ends, missing states, auth/role gaps, misleading UI). Every finding then got an adversarial refutation agent that re-read the actual code. Only findings that survived verification are listed.

- **Total confirmed findings:** 95
- **Severity:** 0 critical · 11 high · 59 medium · 25 low
- **By audit:** code audit 42 · feature/UI audit 54 (deduplicated combined below)

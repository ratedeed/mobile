# Mobile App UI Polish Plan - High Quality

## Goal
Make the RateDee mobile app highly polished by addressing UI/UX gaps while preserving existing high-quality patterns.

---

## Phase 1: Core Component Enhancements

### 1.1 Input Component - Focus & Error States
**Files**: `src/components/common/Input.js`
**Changes**:
- Add `focused` state with border color change (primary500 when focused)
- Add `error` prop with red border and error message display
- Add `success` prop for validation success state
- Animate label (float up on focus)
- Add `leftIcon` and `rightIcon` props

### 1.2 Button Component - Variants
**Files**: `src/components/common/Button.js`
**Changes**:
- Add `variant` prop: `'primary'` | `'secondary'` | `'outline'` | `'ghost'` | `'danger'`
- Add `size` prop: `'sm'` | `'md'` | `'lg'`
- Add `loading` state with spinner
- Add `disabled` state with reduced opacity
- Enhance press animation (scale 0.98 + shadow change)

### 1.3 Card Component - Variants
**Files**: `src/components/common/Card.js`
**Changes**:
- Add `variant` prop: `'elevated'` | `'outlined'` | `'filled'`
- Add `pressable` prop for touch feedback
- Add scale animation on press (card tap effect)
